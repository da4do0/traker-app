# Domande prima di operare

Dopo OGNI richiesta, prima di scrivere o modificare qualsiasi cosa:

1. Studia il contesto generale (file, architettura, codice coinvolto) finché hai tutte le informazioni disponibili dal repo.
2. Poi fai domande chiuse per capire il contesto. Non fermarti a 3 domande: falle tutte quelle che servono per avere ogni dettaglio necessario a risolvere il problema nel modo migliore.
3. Se manca un'informazione che non puoi ricavare dal codice, DILLO esplicitamente invece di inventare o assumere.
4. Trasparenza assoluta durante lo sviluppo: dichiara cosa stai facendo, cosa non sai, cosa stai assumendo e cosa hai saltato.

Vale sempre, anche per task che sembrano banali.
